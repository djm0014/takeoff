# Legacy tools

Backups of the tools this app replaces, kept unchanged.

- `../public/legacy/takeoff-calculator/` — the original sheet goods takeoff
  calculator that used to live at the root of this repo. It is still published
  at `/legacy/takeoff-calculator/` and will inform Milestone 7 (Takeoffs).
- `tools/` — the four bathroom tools exported from their Claude artifacts
  (Niche Rough-In Planner, Vanity Wall Solver, Bathroom Floor Plan, Bathroom
  Site Survey). Each rebuilt screen is checked against these: the same inputs
  must give the same layout, centerlines and rough-in numbers.

Do not edit these files. Fixes go into the new app.
